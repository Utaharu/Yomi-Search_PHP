Yomi-Search PHP - インストール

インストール前の準備

  1. データベース情報の準備

    • データベースのホストアドレス
    • データベースへログインユーザ名
      • ログインする為のパスワード

  2. class/db.phpの編集

    使用するMySQLデータベースに接続するための設定を行います。
    • [class]ディレクトリ内のdb.phpをUTF-8対応エディタで開いて「データベース設定」部分を環境に合わせて変更してください。

  3. ファイルのアップロード

    設定ファイルの編集が完了したら全てのファイルをFFFTPやNextFTPを使ってサーバにアップロードしてください。

  4. アクセス権設定

    サーバ上にある[log]ディレクトリのパーミッションを755に設定。
    • 但し、PHPプログラムがWEBサーバの権限で実行されるサーバでは757または777に設定する必要があります。
      詳しくはサーバ管理者へお問い合わせください。
    • なお、この設定は管理画面からログデータのバックアップを行う場合のみ必須となります。
      バックアップ機能を使用しない場合にはアクセス権の設定を変更する必要はありません。

上記の確認と設定が完了したら「インストール開始」ボタンをクリックしてください。
